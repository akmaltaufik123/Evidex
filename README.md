# CyberOps.TSI (v1.0.1)

> Telegram personal message, channel, and groups scraper engineered for digital forensics and lawful public evidence collection.

---

## 🚀 Overview
**CyberOps** is a Python-based investigation suite leveraging the Telethon library. It allows investigators to securely scrape entire chat histories, text logs, pictures, videos, documents, and audio files from Telegram targets into organized, timestamped directories with live terminal tracking.

---

## 🛠️ Tool Capabilities
* **Full History Scraping:** Extracts entire message history from Telegram channels and groups.
* **Multimodal Extraction:** Pulls text messages, pictures, videos, documents, and audio/sounds.
* **Structured Output:** Automatically creates timestamped directories with dedicated media subfolders.
* **Live Terminal Review:** Real-time review featuring 24-hour time format and day tracking.
* **Flexible Target Lookup:** Supports usernames, public links, or direct numeric IDs.
